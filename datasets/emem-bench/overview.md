# eMEM-Bench

eMEM-Bench 是 eMEM（Hybrid Spatio-Temporal Memory System for Embodied Agents）仓库中的 embodied QA benchmark。

## 与多模态记忆的关系

直接记忆：benchmark 以 AI2-THOR 场景中的历史观察和交互为上下文，要求系统回答空间、时间、实体、情景和内感受问题。

## 数据规模

官方 README 报告 12 个 AI2-THOR 场景、492 个 embodied QA，并提供 `harness.run_benchmark --dataset emem_bench` 运行入口。

## 视频长度与预览

本轮核对的官方 GitHub 仓库没有可直接下载、可核验时长的公开视频 clip，因此本页只放官方静态 eMEM 图示；没有用合成动画替代视频样例。待仓库发布 demo video 后可按同一目录规范补充。
