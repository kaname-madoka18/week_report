# Ego4D Episodic Memory 数据集 overview

核查日期：2026-09-22。来源为 [Ego4D 原始论文](https://arxiv.org/abs/2110.07058)、[官方情景记忆文档](https://ego4d-data.org/docs/benchmarks/episodic-memory/)和[官方仓库](https://github.com/EGO4D/episodic-memory)。本文把原论文规模与本次可读取的官网短视频分开记录。

## 全库、任务与长度

论文标题为 3,000 Hours，正文描述的全库是 **3,670 小时**，来自九个国家的日常第一人称录像；这是原论文版本，今天的正式下载版本可能有更新。全库并不全属于情景记忆任务。

| 情景记忆任务 | 视频小时数 | clip 数 | 平均 clip 长度 | 输出 |
|---|---:|---:|---:|---|
| NLQ（自然语言查询） | 227.1 | 1,659 | 8.2 分钟 | 回答可见的时间窗口 |
| MQ（活动时刻查询） | 328.7 | 2,522 | 7.9 分钟 | 指定活动出现的所有时间区间 |
| VQ2D（视觉查询） | 432.9 | 5,831 | 6.1 分钟 | 查询物体最后出现的时空轨迹/2D框 |
| VQ3D | 13 | 159 | 4.9 分钟 | 增加当前相机到物体的3D位置 |

上表为论文 Table 3 的值，子集可重叠，**不能把这些小时相加当作独立总长度**。官方概括情景记忆为约 74K 个查询、覆盖约 800 小时。NLQ 使用 13 类问题模板，MQ 有 110 个活动类别。这里的 clip 已经过基准切分，并不等于摄像设备每个原始文件的长短。

NLQ 原论文 split 为 train 约136h / val45h / test46h；对应约11.3K / 3.9K / 4.0K queries。后续版本论文的 query 数量可能不同，不能跨版本混合比较。

## 原论文基线结果

以下引用原论文附录，未进行模型运行或今天排行榜复现。

| 方法 / 条件 | NLQ test R@1 @IoU0.3 | R@5 @IoU0.3 | R@1 @IoU0.5 |
|---|---:|---:|---:|
| 2D-TAN | 5.80% | 13.90% | 2.34% |
| VSLNet | 5.47% | 11.21% | 2.80% |

NLQ 评价时间定位召回，不是开放式问答正确率。VQ2D 的 Siam-RCNN + KYS（Residual）基线 test Success=41.6%、tAP=0.12、stAP=0.05；这些是另一种物体时空定位指标，不能与 NLQ 的百分比直接比较。

## 发布状态与此次预览

[官方首页下载部分](https://ego4d-data.org/#download)要求先签署 Ego4D 许可才能获取完整视频、元数据和标注。本次只读取公开文档、仓库树和无需登录的官网短演示，没有申请许可，也没有读取受限全库。

找到官网仓库的 12 个地区演示 MP4，每个都先从 GitHub tree 核验大小小于 100,000,000 bytes，再通过 GitHub blob API 获取并用 Git blob SHA1 核对内容。共 **1,200 张真实视频帧，12 个地区分组各 100 张**。这些显示实际采集环境，不代表 NLQ/MQ/VQ 的已标注样本；由于没有可靠映射，不给演示虚构任务标签。

## 第二版短视频展示

本次第二版预览把本地完整副本不超过 **180 秒** 的视频改为直接播放的 video case 卡片，不再为这些短视频重复生成 100 帧图片；较长视频、没有安全本地副本的视频仍保留抽帧预览。当前项目检测到 **12 个**短视频 case，播放文件均小于 100 MB；页面中的时长、大小与 SHA-256 来自本地文件核验。
