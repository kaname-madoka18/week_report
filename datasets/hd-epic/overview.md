# HD-EPIC 数据集 overview

核查日期：2026-09-22；论文结果按 arXiv v1 快照整理。[论文](https://arxiv.org/abs/2502.04144)发表于 CVPR 2025；[官网](https://hd-epic.github.io/site/)与[标注仓库](https://github.com/hd-epic/hd-epic-annotations)提供数据和更新。本次拿到官方 **156 段逐视频时长 CSV**，比只用论文“41小时”更精确。

## 视频规模与完整长度清单

## 标注与任务

69 种食谱、558 种食材、59,454 个细粒度动作（动作段均长2.0s）、50,968 个声音事件、19.9K 物体移动轨迹、7.7M 手部 masks，以及物体框、眼动提前注视、3D fixtures、营养信息。**动作段长度和物体轨迹长度不是整段视频长度**。

VQA 有 26,650 个五选一问题，分食谱、食材、营养、细粒度动作、3D 感知、物体运动、眼动七类，共30个问题原型。输入长度可从单帧到拼接后的7小时以上，七类问题共用视频，不能按七类推断七个独立视频子库。

## 主要论文结果与评测条件

| 原论文 VQA baseline | 平均 accuracy |
|---|---:|
| Llama 3.2，仅语言 | 26.5% |
| Gemini Pro，仅语言 | 26.7% |
| VideoLlama 2 | 27.4% |
| LongVA | 29.3% |
| LLaVA-Video | 32.4% |
| Gemini Pro，视频+问答 | **38.5%** |
| 抽样人工基线 | 90.3% |

表值来自论文 Table 2，以题型原型结果汇总；五选一随机水平20%。人工是抽样基线，不是全部26,650题都由同样人数作答。HD-EPIC 作为验证集使用，动作识别比较的是 EPIC-KITCHENS-100 训练的公开权重迁移，例如 TIM (V) 的动作准确率23.9%；它不代表在 HD-EPIC 上训练后的最佳成绩。本次未复现模型或追踪最新挑战榜。

## 获取与真实预览

官网给出 MP4 约115.5GB、VRS约1.9TB，以及独立音频/SLAM/眼动等下载入口。公开数据可分部分下载；本次未下载完整原始 MP4。对9位参与者各选一段发出 HTTP Range 请求，但 Bristol 的连接/传输速度使批量取样无法稳定完成，保留了已解码的小量真实帧。

为了提供可立即浏览的100帧预览，使用作者官网 **`opening.gif` 动态概览**：先从官方 GitHub 文件树确认大小23,028,540 bytes（23.029MB，小于100MB），完整读取后核对 Git blob SHA1，再从其10.2秒动画中抽100个不同时刻。画面是作者发布的真实厨房录像拼图和标注演示，**不是从156个视频随机抽取100段**。

[离线图册](preview_gallery.html)主分组100帧，另有10张原 MP4 Range 帧；后者未满足每位参与者100帧，界面明确标记部分预览。
