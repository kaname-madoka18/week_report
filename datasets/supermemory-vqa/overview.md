## 数据与视频长度

| 项目 | 已知情况 |
|---|---|

| QA 数量 | 4,853，人工参与核验的选择题 |

| 多证据问题 | README 表中声明 34% |

六类任务为物体与位置记忆、对话记忆、视觉场景回忆、上下文检索、时间线重建、意图回忆。选项有正确、模糊、错误、无法回答等层次，用来衡量证据不足时的回答行为。六类是 QA 能力维度；没有依据可将 52.9 小时划分为六组互斥视频。

## 论文结果与可复现状态

当前公开 README 介绍两阶段标注流水线：先按时间顺序生成视频描述，再构建全局事件记录、生成并核验问题。没有正式模型分数表、训练/验证/测试划分或完整论文，因此本 overview 不填模型准确率。代码中的 `chunk_duration=60` 是可配置处理窗口，**不能当作源视频固定长度**。
