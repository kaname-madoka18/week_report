# EgoMem 数据与视频 overview

核查日期：2026-09-22。对应论文是 [EgoMem: Lifelong Memory Agent for Full-duplex Omnimodal Models](https://arxiv.org/abs/2509.11914)（本次读取 v2），作者 Yiqun Yao 等。**它不是 VideoLucy 发布的同名 EgoMem 长视频问答 benchmark**，也不对应搜索中其他作者的同名机器人库。

## 真正使用的数据

这是实时音视频对话记忆系统，不是发布数百小时第一人称视频的论文。附录 C 用 DeepSeek-V3 合成用户档案与个性化文本回答，再通过 TTS、噪声与回声增强组织成全双工数据流。

| 数据层次 | 规模与来源 |
|---|---|
| Level-1 | 500 个用户档案、90 维 persona；10,000 段对话，通常每段 3–5 轮 |
| Level-2 | 500 种可能关系；主用户与 3–5 个关联用户组成图；5,000 段对话 |
| 训练组合 | Level-1 158K 个上下文/监督组合；Level-2 54K，加 50% Level-1；另含 clean/noisy 版本 |
| 分段触发器 | 100K clean + 100K noised 训练样本；留出 1,000 样本测试 |
| 人脸/声纹模块评测 | LFW、VoxCeleb、SeedTTS-eval；不是本项目新拍摄的视频库 |

## 长度应如何理解

论文把多名用户的多段对话拼成最长 **8,192 个时间步**的 token stream。Mimi 的音频时间步为 12.5 Hz，故理论跨度为 **655.36 秒，约 10.92 分钟**。其中部分位置留给 memory chunk，实际有效对话更短。论文没有公开每段源 MP4 的长度、所有对话的总小时数或完整数据文件清单，不能用 15K 对话乘上述最大值估计视频时长。视觉输入每 2–4 秒插入一次；论文的 20+ fps 吞吐是音频 token 帧率，也不是摄像头 FPS。

## 论文主要结果与条件

以下为原论文结果，本次没有训练或复现实验。

| 评测 | 结果 | 条件 |
|---|---|---|
| 人脸验证 | 98.4% accuracy | LFW，已有 DeepFace 方案 |
| 声纹检索 | 96.5% pass@1 | 1,000 query / 120 key；adaptive s-norm |
| 文本检索 | 96.0% pass@5 | 200 query，从 500 条关系/个人事实检索 |
| 对话边界 | clean F1 0.986；noisy 0.982 | 容许 ±5 时间步，即 ±0.4 秒；不是精确边界 F1 |
| Level-1 事实一致性 | clean 0.959；noisy 0.931 | RoboEgo 个性化对话，DeepSeek-V3 按轮打 0/1 分 |
| Level-2 事实一致性 | clean 0.895；noisy 0.876 | 同上，需关系/内容检索 |

个性化回答评估向打分模型提供用户指令、参考回答、memory 内容和 RoboEgo 生成文本，不是直接人工逐帧评估视频记忆。论文还报告与人工评估的一致性；这里保留其自动打分条件。
