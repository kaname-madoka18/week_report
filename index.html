01 / CORE QUESTION

用家庭中的实际任务，检验多模态记忆。

围绕物体位置、提示音和细粒度视觉线索设计任务，考察机器人能否利用记忆，在家庭场景中完成空间定位、移动与操作。

MEMORY / 01⌁

空间与物体位置

记住桌面及抽屉中物体的位置，根据随机指令找到目标，完成定位、移动和取放。

MEMORY / 02◌

音频序列记忆

记住听到的提示音，并据此执行操作，例如按照音阶顺序按下五个按钮。

MEMORY / 03↗

视觉细粒度记忆

从众多手办中辨认异形目标，或区分相近色阶的口红，考察难以仅靠语言描述解决的视觉记忆。

让记忆支撑

评测目标 / Memory for embodied tasks
01

多模态记忆评测主要面向 QA

缺少对机器人利用记忆、在物理世界中实际完成任务的考察。

LIMIT
02

记忆形式单一，容易依赖捷径

仅保存文字 caption，或将首帧图像放入上下文，就可能获得高分，难以检验多模态记忆能力。

HACK
03

场景简单，操作链路短

物体少、任务简单、操作时间短，且主要局限于桌面；家庭任务需要空间定位、移动与操作的全链路能力。

SCOPE

02 / BENCHMARK LOOP

让记忆贯穿连续的家庭任务流。

每个家庭 session 包含多次观察、指令与行动；评测记录记忆如何写入、被召回并持续更新。

01

感知家庭状态

在客厅、厨房和抽屉等区域建立可持续更新的场景索引。

RGB-D · AUDIO
02

持续写入记忆

把视觉、音频、空间和动作结果写入跨时段可检索的家庭记忆。

MEMORY UPDATE
03

跨任务检索

任务切换或环境变化时，召回相关历史并判断哪些状态仍然有效。

CONTEXT RETRIEVAL
04

执行并校正

执行导航、抓取、按键或放置，检查结果并把新状态写回记忆。

ACT · UPDATE

03 / PROJECT ARCHITECTURE

把家庭记忆、空间状态和行动结果串成一条链。

架构核心是“长期记忆 → 空间 grounding → 行动反馈 → 状态更新”的闭环；每个模块都能独立替换、记录和对比。

05 / TASK MATRIX

三类能力，在连续家庭任务中反复检验。

每类任务都可以在不同房间、视角和时间点组合，检验记忆是否真的支撑了持续行动。

Spatial / ObjectT–01

连续房间任务 + Pick & Place

在多次家庭任务之间切换，持续跟踪桌面、抽屉和被移动物体的位置。

关键观测跨视角空间关系、导航、抓取和放置的全链路完成率。
Audio / SequenceT–02

提示音驱动的五键操作

机器人根据提示音或音阶记住顺序，随后在视线变化或延迟后按下五个按钮。

关键观测音频编码、时序保持、动作节奏和错误恢复。
Visual / Fine-grainedT–03

异形物体与相近色阶

从一组手办中找到指定异形物体，或从相近颜色的口红中选出目标。

关键观测细粒度视觉记忆、遮挡下辨识和指令与物体的 grounding。

06 / 可行性分析 · FEASIBILITY

先把闭环跑通，再把难度推到边界。

仿真器降低硬件和数据采集成本，Astra 作为 Agentic 基线验证当前最强模型的能力上限。

落地条件 READY / HIGH

仿真环境

先构建轮式夹爪机器人、家庭房间、抽屉和可交互物体，任务可重复回放。

模型接入

Astra 负责串起感知、记忆、规划和工具调用，模块边界便于替换基线。

评测闭环

保留动作、碰撞、时间、路径和记忆召回证据，支持结果与失败原因双重评分。

关键风险 WATCH / MEDIUM

系统协同

高层 planner 与执行器边界不清会导致反复调用；用结构化 action contract 固定交接。

记忆成本

多模态原始流太大；采用事件摘要、关键帧和空间索引，按需检索而非全量注入。

空间误差

第一视角感知与全局坐标可能漂移；保留不确定性并允许主动补观测、重新规划。
